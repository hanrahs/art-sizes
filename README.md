# Art Sizes

A small phone app for measuring paintings before a move, so the right boxes can be ordered.

- Tap **Add a painting**, take a photo, give it a name you'll recognise, and enter the height, width and depth in cm.
- Exports a CSV spreadsheet (height, width and depth in separate columns) and a printable list (with or without photos).
- Backs up names and sizes to any cloud drive through the share menu. Photos stay on the phone and aren't included in backups.

All data stays on the device. There's no server and no account.

## Install

Open the site in Chrome on Android → ⋮ → **Add to Home screen**.

## Updating

After changing any file, bump `VERSION` in `sw.js` so installed copies pick up the change.
